        <div class="mat-section" id="mat-p1">
          <div class="section-head">
            <h3>1. Leasing financiero, operativo y leaseback</h3>
            <div class="badges">
              <span class="badge fuente">O1</span>
              <span class="badge pareto">Pareto</span>
            </div>
          </div>
          <p class="enunciado-q">¿Qué distingue al leasing financiero del leasing operativo, y dónde encaja el leaseback en esa clasificación?</p>
          <details>
            <summary>Ver respuesta</summary>
            <div class="detail-content">
              <p><b>(a) Leasing financiero (art. 1231 incs. a, b y c CCCN):</b></p>
              <p>El dador adquiere el bien de un tercero por indicación, especificación o sustitución del tomador en una compraventa que este ya había celebrado.</p>
              <p style="margin-top:10px;"><b>(b) Leasing operativo (art. 1231 inc. d):</b></p>
              <p>El bien ya es propiedad del dador antes de vincularse con el tomador: no hay ninguna gestión de compra a un tercero.</p>
              <p style="margin-top:10px;"><b>(c) Leaseback (art. 1231 inc. e):</b></p>
              <p>Es un tercer género: el tomador vende su propio bien al dador, que se lo entrega nuevamente en leasing — funciona como mecanismo de autofinanciamiento, no de adquisición de un bien nuevo.</p>
            </div>
          </details>
          <details class="error-detail">
            <summary>Ver error típico</summary>
            <div class="detail-content"><b>❌ Error típico:</b> Tratar al leaseback como una simple compraventa, sin advertir que el vendedor conserva el uso del bien como tomador.</div>
          </details>
        </div>

        <div class="mat-section" id="mat-p2">
          <div class="section-head">
            <h3>2. Mora y desalojo en leasing inmobiliario</h3>
            <div class="badges">
              <span class="badge fuente">S3</span>
              <span class="badge cae">Cae siempre</span>
            </div>
          </div>
          <p class="enunciado-q">Si un tomador de leasing sobre un inmueble adeuda un cuarto o más pero menos de tres cuartas partes del canon pactado, ¿qué procedimiento debe seguir el dador antes de poder pedir el desalojo?</p>
          <details>
            <summary>Ver respuesta</summary>
            <div class="detail-content">
              <p><b>(a)</b> La mora es automática, sin necesidad de interpelación previa para que se produzca.</p>
              <p style="margin-top:10px;"><b>(b)</b> El dador debe intimar al tomador al pago de los períodos adeudados con más sus intereses, otorgándole un plazo <b>no menor a 60 días</b> desde la notificación.</p>
              <p style="margin-top:10px;"><b>(c)</b> Vencido ese plazo sin que se verifique el pago, recién ahí el dador puede demandar el desalojo, dando previamente vista al tomador por 5 días.</p>
            </div>
          </details>
          <details class="error-detail">
            <summary>Ver error típico</summary>
            <div class="detail-content"><b>❌ Error típico:</b> Aplicar directamente el tramo de "menos de un cuarto" (vista de 5 días sin intimación previa de 60 días) a un tomador que ya pagó más de un cuarto del canon.</div>
          </details>
        </div>

        <div class="mat-section" id="mat-p3">
          <div class="section-head">
            <h3>3. Determinación de la comisión del corredor</h3>
            <div class="badges">
              <span class="badge fuente">O2</span>
            </div>
          </div>
          <p class="enunciado-q">Si las partes no pactaron el monto de la comisión del corredor, ¿cómo se determina?</p>
          <details>
            <summary>Ver respuesta</summary>
            <div class="detail-content">
              <p>Se aplica el <b>uso del lugar de celebración del contrato</b>; en su defecto, el <b>uso del lugar donde el corredor principalmente realizó su cometido</b>; y si tampoco existe un uso determinado, la fija el <b>juez</b>.</p>
            </div>
          </details>
          <details class="error-detail">
            <summary>Ver error típico</summary>
            <div class="detail-content"><b>❌ Error típico:</b> Creer que, a falta de pacto, el corredor no tiene derecho a cobrar nada.</div>
          </details>
        </div>

        <div class="mat-section" id="mat-p4">
          <div class="section-head">
            <h3>4. Confidencialidad del corredor</h3>
            <div class="badges">
              <span class="badge fuente">S4</span>
              <span class="badge trampa">Trampa</span>
            </div>
          </div>
          <p class="enunciado-q">¿Por qué el incumplimiento del deber de confidencialidad del corredor genera responsabilidad objetiva, y no exige probar culpa o dolo?</p>
          <details>
            <summary>Ver respuesta</summary>
            <div class="detail-content">
              <p>No revelar información confidencial conocida por su intervención es una <b>obligación de no hacer</b>, y el régimen de las obligaciones de no hacer responde a un <b>factor de atribución objetivo</b>. Basta con que el corredor haya revelado o usado indebidamente la información para que responda, sin necesidad de indagar su intención.</p>
              <p style="margin-top:10px;"><b>Nota de corrección:</b> El deber está regulado en el <b>art. 992 CCCN</b> (no en los arts. 1391/1392 como aparecía en la transcripción de la clase, que pertenecen al capítulo de contratos bancarios).</p>
            </div>
          </details>
          <details class="error-detail">
            <summary>Ver error típico</summary>
            <div class="detail-content"><b>❌ Error típico:</b> Citar los arts. "1391" y "1392" CCCN para este deber — esos artículos pertenecen al capítulo de contratos bancarios; la numeración correcta es arts. 991 (buena fe, factor subjetivo) y 992 (confidencialidad, factor objetivo).</div>
          </details>
        </div>

        <div class="mat-section" id="mat-p5">
          <div class="section-head">
            <h3>5. Exclusividad territorial en la concesión</h3>
            <div class="badges">
              <span class="badge fuente">O3</span>
              <span class="badge trampa">Trampa</span>
            </div>
          </div>
          <p class="enunciado-q">¿Es la exclusividad territorial un elemento esencial del contrato de concesión?</p>
          <details>
            <summary>Ver respuesta</summary>
            <div class="detail-content">
              <p><b>No.</b> Es un <b>elemento natural</b>, no esencial: admite pacto en contrario (arts. 1503, 1504 inc. b y 1505 inc. b). De existir, suele referirse al territorio, pero incluso así el concedente puede reservarse ventas directas a clientes especiales, como el Estado, diplomáticos o compradores de grandes volúmenes anuales.</p>
            </div>
          </details>
          <details class="error-detail">
            <summary>Ver error típico</summary>
            <div class="detail-content"><b>❌ Error típico (T4):</b> Dar por sentado que toda concesión es exclusiva por su sola naturaleza jurídica.</div>
          </details>
        </div>

        <div class="mat-section" id="mat-p6">
          <div class="section-head">
            <h3>6. Retribución del concesionario vs. comisión del corredor</h3>
            <div class="badges">
              <span class="badge fuente">O3, D2</span>
              <span class="badge trampa">Trampa</span>
            </div>
          </div>
          <p class="enunciado-q">¿Por qué no es técnicamente correcto llamar "comisión" a la retribución del concesionario?</p>
          <details>
            <summary>Ver respuesta</summary>
            <div class="detail-content">
              <p>El concesionario actúa a <b>nombre y por cuenta propia</b>, comprando y revendiendo mercaderías a riesgo propio; no media un negocio ajeno como el corredor. Por eso su ganancia es, en principio, la <b>diferencia entre el precio que paga al concedente y el que obtiene en la reventa</b> ("margen comercial"), aunque el art. 1507 CCCN también admite que se pacte como comisión, margen sobre unidades o cantidades fijas.</p>
            </div>
          </details>
          <details class="error-detail">
            <summary>Ver error típico</summary>
            <div class="detail-content"><b>❌ Error típico (T1):</b> Confundir esta retribución con la comisión del art. 1350 CCCN, que corresponde específicamente al corredor.</div>
          </details>
        </div>

        <div class="mat-section" id="mat-p7">
          <div class="section-head">
            <h3>7. Concesión vs. distribución</h3>
            <div class="badges">
              <span class="badge fuente">O4, D3</span>
            </div>
          </div>
          <p class="enunciado-q">¿Cuál es la diferencia esencial entre el contrato de concesión y el de distribución?</p>
          <details>
            <summary>Ver respuesta</summary>
            <div class="detail-content">
              <p><b>(a)</b> La <b>concesión</b> está tipificada en el CCCN (arts. 1502 a 1511); la <b>distribución</b> es un contrato atípico, sin regulación propia, cuyo concepto fue moldeado por doctrina y jurisprudencia.</p>
              <p style="margin-top:10px;"><b>(b)</b> El distribuidor tiene <b>mayor autonomía</b> frente al distribuido que el concesionario frente al concedente.</p>
              <p style="margin-top:10px;"><b>(c)</b> La actividad del distribuidor <b>no comprende las obligaciones de posventa</b> del producto, a diferencia de la del concesionario.</p>
            </div>
          </details>
          <details class="error-detail">
            <summary>Ver error típico</summary>
            <div class="detail-content"><b>❌ Error típico (T7):</b> Atribuirle a la distribución reglas propias de plazo o extinción, cuando en realidad se toman prestadas de la concesión por remisión del art. 1511 inc. b.</div>
          </details>
        </div>

        <div class="mat-section" id="mat-p8">
          <div class="section-head">
            <h3>8. Leasing y concurso preventivo</h3>
            <div class="badges">
              <span class="badge fuente">S2</span>
              <span class="badge cae">Cae siempre</span>
              <span class="badge trampa">Trampa</span>
            </div>
          </div>
          <p class="enunciado-q">Si el tomador de un leasing entra en concurso preventivo, ¿qué ocurre con el contrato?</p>
          <details>
            <summary>Ver respuesta</summary>
            <div class="detail-content">
              <p>El CCCN <b>no regula expresamente</b> los efectos del concurso o la quiebra sobre el leasing; la regla práctica es que <b>el contrato sigue su curso</b> pese al concurso de cualquiera de las partes.</p>
              <p style="margin-top:10px;">El supuesto específico de la quiebra está regulado en la <b>Ley de Leasing 25.248</b>, no en el Código.</p>
            </div>
          </details>
          <details class="error-detail">
            <summary>Ver error típico</summary>
            <div class="detail-content"><b>❌ Error típico (T5):</b> Suponer que la apertura del concurso resuelve automáticamente el contrato o habilita al dador a recuperar el bien de inmediato.</div>
          </details>
        </div>

        <div class="mat-section" id="mat-int">
          <div class="section-head">
            <h3>Integradora · El corredor Ferretti</h3>
            <div class="badges">
              <span class="badge cae">Cae siempre</span>
            </div>
          </div>
          <div class="contexto-caso">
            Mediante la intervención del corredor Bruno Ferretti, las empresas Aránzazu S.A. (vendedora) y Kowalski Hnos. S.A. (compradora) negocian la venta de un inmueble industrial. En el curso de la negociación, Ferretti toma conocimiento confidencial de que Aránzazu S.A. atraviesa una caída de rentabilidad y necesita vender con urgencia. Se lo revela a Kowalski Hnos. S.A., esperando que esta le encargue futuros negocios de intermediación.
          </div>
          <p class="enunciado-q">(a) ¿Qué deber del corredor vulnera Ferretti con esa revelación, y en qué artículo del CCCN está regulado correctamente?</p>
          <p class="enunciado-q">(b) ¿Qué tipo de obligación incumple y qué factor de atribución le resulta aplicable?</p>
          <p class="enunciado-q">(c) Si de esa revelación se deriva un perjuicio para Aránzazu S.A., ¿qué consecuencia jurídica puede seguirse para Ferretti?</p>
          <details>
            <summary>Ver resolución completa</summary>
            <div class="detail-content">
              <p><b>(a)</b> Vulnera el <b>deber de confidencialidad</b> del corredor, regulado en el <b>art. 992 CCCN</b> (la transcripción de la clase citó por error los arts. 1391/1392, que en realidad pertenecen al capítulo de contratos bancarios).</p>
              <p style="margin-top:10px;"><b>(b)</b> Es una <b>obligación de no hacer</b> —no revelar ni usar en beneficio propio o ajeno la información confidencial conocida por su intervención— y ese tipo de obligación responde a un <b>factor de atribución objetivo</b>, sin necesidad de probar culpa o dolo de Ferretti.</p>
              <p style="margin-top:10px;"><b>(c)</b> Ferretti queda obligado a <b>resarcir el daño</b> causado a Aránzazu S.A. y puede además <b>perder su derecho a cobrar la comisión</b> pactada, dado que su conducta contraría los deberes que hacen a la imparcialidad de la mediación (arts. 1347 y 1348 CCCN).</p>
            </div>
          </details>
          <details class="error-detail">
            <summary>Ver error típico</summary>
            <div class="detail-content"><b>⚠ Error típico:</b> Creer que, para responsabilizar a Ferretti, hace falta demostrar que actuó con mala fe o intención de dañar — al tratarse de una obligación de no hacer con factor objetivo, ese análisis subjetivo es innecesario.</div>
          </details>
        </div>

        <div class="mat-section" id="mat-c1">
          <div class="section-head">
            <h3>Caso 1 · El galgo que volvió a casa</h3>
            <div class="badges">
              <span class="badge fuente">Simple</span>
              <span class="badge fuente">O1</span>
              <span class="badge fuente">art. 1231 inc. e</span>
            </div>
          </div>
          <div class="contexto-caso">
            Mariano Sasso es titular de una camioneta de alta gama que utiliza para su actividad profesional. Necesitado de liquidez, se la vende a Global Renting S.A. (empresa financiera) y esta, en el mismo acto, se la entrega nuevamente en leasing: Sasso sigue usando la camioneta mientras paga cánones mensuales, con la posibilidad de recomprarla al final del contrato.
          </div>
          <details>
            <summary>Ver resolución</summary>
            <div class="detail-content">
              <p><b>Figura jurídica:</b> Leaseback (sale and leaseback), art. 1231 inc. e) CCCN.</p>
              <p style="margin-top:10px;"><b>Razonamiento:</b></p>
              <ol>
                <li>Sasso es titular de un bien propio que decide vender.</li>
                <li>El comprador (Global Renting S.A.) es, a la vez, quien se lo entrega nuevamente en leasing.</li>
                <li>Sasso, ahora tomador, conserva el uso del bien y paga cánones con miras a recomprarlo — esa es la estructura típica del inciso e) del art. 1231.</li>
                <li>La operación funciona como mecanismo de autofinanciamiento para Sasso, que obtiene liquidez sin perder el uso de la camioneta.</li>
              </ol>
              <p style="margin-top:10px;"><b>Respuesta:</b> Se configura un leaseback (art. 1231 inc. e CCCN). Sasso vende el bien a Global Renting S.A., que se lo entrega de nuevo en leasing, permitiéndole autofinanciarse sin perder el uso de la camioneta.</p>
            </div>
          </details>
          <details class="error-detail">
            <summary>Ver error típico</summary>
            <div class="detail-content"><b>❌ Error típico:</b> Confundir esta operación con una simple compraventa, sin advertir que el vendedor conserva el uso del bien como tomador; o clasificarla como leasing financiero, que exige que el dador adquiera el bien de un tercero indicado por el tomador, no del propio tomador.</div>
          </details>
          <p class="link-rel">🔗 Relacionado con P1 del cuestionario.</p>
        </div>

        <div class="mat-section" id="mat-c2">
          <div class="section-head">
            <h3>Caso 2 · La "comisión" de AutoValle</h3>
            <div class="badges">
              <span class="badge trampa">Trampa</span>
              <span class="badge fuente">T1, O2, O3, D2</span>
              <span class="badge fuente">arts. 1350 y 1507 CCCN</span>
            </div>
          </div>
          <div class="contexto-caso">
            La concesionaria AutoValle comercializa vehículos de la marca Kestrel bajo un contrato de concesión con Kestrel Argentina S.A., y factura mensualmente a la terminal un monto en concepto de "comisión por unidad vendida". Al analizar el contrato para el final, un estudiante sostiene que esa comisión se rige por el art. 1350 CCCN, igual que la comisión de un corredor.
          </div>
          <details>
            <summary>Ver resolución</summary>
            <div class="detail-content">
              <p><b>Figura jurídica:</b> Retribución del concesionario (art. 1507 CCCN), distinta de la comisión del corretaje (art. 1350 CCCN).</p>
              <p style="margin-top:10px;"><b>Razonamiento:</b></p>
              <ol>
                <li>El concesionario actúa a nombre y por cuenta propia, comprando y revendiendo los vehículos a su propio riesgo, no mediando un negocio ajeno como el corredor.</li>
                <li>Por eso, aunque el contrato o la práctica comercial llamen "comisión" a esa suma, técnicamente se trata de la retribución del art. 1507 CCCN, que puede consistir en un margen, una comisión o cantidades fijas, según lo pactado con el concedente.</li>
                <li>El art. 1350 CCCN regula específicamente la comisión del corredor, que media —sin representar ni asumir riesgo propio— entre dos partes que no son él mismo.</li>
                <li>La denominación comercial "comisión" no cambia la naturaleza jurídica del vínculo: AutoValle no es un intermediario neutral, sino que compra y revende a su propio riesgo.</li>
              </ol>
              <p style="margin-top:10px;"><b>Respuesta:</b> El estudiante se equivoca. El nombre comercial "comisión" no determina el régimen aplicable: la retribución de AutoValle se rige por el art. 1507 CCCN, no por el art. 1350 CCCN, porque AutoValle actúa a riesgo propio y no media un negocio ajeno.</p>

        <div class="mat-section" id="mat-c3">
          <div class="section-head">
            <h3>Caso 3 · El galpón de Herrajes del Sur</h3>
            <div class="badges">
              <span class="badge fuente">Complejo</span>
              <span class="badge fuente">O1, S2, S3, T5, T6</span>
              <span class="badge fuente">arts. 1231, 1248, 1249; Ley 25.248</span>
            </div>
          </div>
          <div class="contexto-caso">
            Herrajes del Sur SRL tomó en leasing operativo (art. 1231 inc. d) un galpón industrial de propiedad de Inverfin S.A., comprometiéndose a pagar 48 cánones mensuales. Tras abonar 20 cuotas, dejó de pagar durante cuatro meses consecutivos. Mientras Inverfin S.A. evaluaba iniciar el trámite de desalojo, Herrajes del Sur SRL se presentó en concurso preventivo. El abogado de Inverfin S.A. sostiene que, al haberse abierto el concurso, el contrato de leasing queda automáticamente resuelto y el galpón debe restituirse de inmediato.
          </div>
          <details>
            <summary>Ver resolución</summary>
            <div class="detail-content">
              <p><b>Figura jurídica:</b> Incumplimiento y mora en el leasing inmobiliario (art. 1248), y efecto del concurso preventivo sobre el contrato de leasing (S2).</p>
              <p style="margin-top:10px;"><b>Razonamiento:</b></p>
              <ol>
                <li>Herrajes del Sur SRL pagó 20 de 48 cuotas (algo más de un cuarto, menos de tres cuartas partes), por lo que corresponde el tramo intermedio del <b>art. 1248 inc. b)</b>: mora automática, con intimación por un plazo no menor a 60 días.</li>
                <li>La apertura del concurso preventivo <b>no extingue automáticamente</b> el contrato de leasing: la regla general es que el contrato sigue su curso pese al concurso o la quiebra de cualquiera de las partes.</li>
                <li>El régimen específico de los efectos de la quiebra sobre el leasing está en la <b>Ley de Leasing 25.248</b>, no en el CCCN, por lo que el abogado de Inverfin S.A. no puede fundar la resolución automática en el Código.</li>
                <li>Inverfin S.A. debe seguir el procedimiento del art. 1248 (intimación, plazo, eventual desalojo) y, en paralelo, verificar su crédito por los cánones adeudados dentro del proceso concursal.</li>
              </ol>
              <p style="margin-top:10px;"><b>Respuesta:</b> El abogado de Inverfin S.A. está equivocado. El concurso preventivo no resuelve automáticamente el leasing; el contrato sigue vigente y Inverfin S.A. debe cumplir el procedimiento del art. 1248 inc. b) (intimación con plazo no menor a 60 días) antes de poder demandar el desalojo, además de verificar su crédito en el concurso.</p>
            </div>
          </details>
          <details class="error-detail">
            <summary>Ver error típico</summary>
            <div class="detail-content"><b>❌ Error típico (T5):</b> Suponer que el concurso o la quiebra de una de las partes extingue automáticamente el leasing, cuando la regla es la continuidad del contrato, con reenvío a la Ley 25.248 para los efectos específicos de la quiebra.</div>
          </details>
          <p class="link-rel">🔗 Relacionado con P8 del cuestionario.</p>
          <div class="contrafactico">
            <b>Sub-escenario contrafáctico:</b> ¿Cómo cambiaría el análisis si el galpón fuera reemplazado por una flota de camiones (bien mueble) en las mismas condiciones de mora?<br><br>
            <b>Resolución contrafáctica:</b> Si el objeto fuera un bien mueble, no correspondería el esquema escalonado del art. 1248 (pensado para inmuebles), sino el del <b>art. 1249</b>: ante la mora automática, Inverfin S.A. podría optar directamente por el secuestro del bien —previa interpelación por un plazo no menor a cinco días— o por la vía ejecutiva para el cobro del canon adeudado, sin el tramo de intimación de 60 días propio de los inmuebles. El concurso preventivo de Herrajes del Sur SRL seguiría sin resolver automáticamente el contrato, por la misma razón de S2.
          </div>

const STORAGE_KEY = "contratos_clase3_progress";

const state = {
  queue: [],
  current: null,
  phase: "recall",
  progress: {},
  sessionStats: { ok: 0, err: 0 },
  mode: "full",
  viewedCount: 0,
  flashcards: {
    index: 0,
    revealed: false,
    order: []
  }
};

function saveProgress() {
  try {
    const data = { progress: state.progress, sessionStats: state.sessionStats };
    localStorage.setItem(STORAGE_KEY, JSON.stringify(data));
  } catch (e) {}
}

function loadProgress() {
  try {
    const raw = localStorage.getItem(STORAGE_KEY);
    if (!raw) return false;
    const data = JSON.parse(raw);
    if (data && data.progress) state.progress = data.progress;
    if (data && data.sessionStats) state.sessionStats = data.sessionStats;
    return true;
  } catch (e) { return false; }
}

function clearProgress() {
  try { localStorage.removeItem(STORAGE_KEY); } catch (e) {}
}

function $(sel) { return document.querySelector(sel); }
function showScreen(id) {
  document.querySelectorAll(".screen").forEach(s => s.classList.remove("active"));
  document.getElementById(id).classList.add("active");
  window.scrollTo({ top: 0, behavior: "smooth" });
}

function getProgress(qid) {
  if (!state.progress[qid]) state.progress[qid] = { okCount: 0, errCount: 0, mastered: false, attempts: 0 };
  return state.progress[qid];
}
function isMastered(qid) { return getProgress(qid).mastered; }

function buildQueue(mode) {
  let pool = mode === "weak" ? QUESTIONS.filter(q => !isMastered(q.id)) : [...QUESTIONS];
  const order = { critico: 0, alto: 1, medio: 2 };
  pool.sort((a,b) => order[a.priority] - order[b.priority]);
  const groups = { critico: [], alto: [], medio: [] };
  pool.forEach(q => groups[q.priority].push(q));
  Object.values(groups).forEach(g => shuffle(g));
  state.queue = [...groups.critico, ...groups.alto, ...groups.medio];
  state.viewedCount = 0;
}
function shuffle(arr) {
  for (let i = arr.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [arr[i], arr[j]] = [arr[j], arr[i]];
  }
}
function reinsertLater(q) {
  const insertAt = Math.min(state.queue.length, 2 + Math.floor(Math.random() * 3));
  state.queue.splice(insertAt, 0, q);
}
function countMastered() { return QUESTIONS.filter(q => isMastered(q.id)).length; }

function hasWeakQuestions() {
  return QUESTIONS.some(q => !isMastered(q.id) && getProgress(q.id).attempts > 0);
}

function updateReviewOnlyButtonVisibility() {
  const btn = $("#btn-review-only");
  if (hasWeakQuestions()) btn.classList.remove("hidden");
  else btn.classList.add("hidden");
}

function renderQuestion() {
  if (state.queue.length === 0) { renderSummary(); return; }
  state.current = state.queue.shift();
  state.phase = "recall";
  state.viewedCount++;
  updateProgressBar();
  drawQuestion();
}

function updateProgressBar() {
  const total = QUESTIONS.length;
  const mastered = countMastered();
  const currentNum = Math.min(state.viewedCount, total);
  $("#stat-current").textContent = currentNum;
  $("#stat-total").textContent = total;
  $("#stat-mastered").textContent = mastered;
  $("#progress-fill").style.width = ((mastered / total) * 100) + "%";
}

function drawQuestion() {
  const q = state.current;
  const p = getProgress(q.id);
  const container = $("#question-container");
  let prioridadLabel = "";
  if (q.priority === "critico") prioridadLabel = '<span class="priority critico">Crítico</span>';
  else if (q.priority === "alto") prioridadLabel = '<span class="priority alto">Alto</span>';
  else prioridadLabel = '<span class="priority medio">Medio</span>';
  const counterBadge = `
    <span class="counter-badge ${p.okCount>0?'ok':''}">✓ ${p.okCount}/2</span>
    ${p.errCount>0 ? `<span class="counter-badge err">✗ ${p.errCount}</span>` : ""}
  `;
  container.innerHTML = `
    <div class="card">
      <div class="tag-row">
        <span class="tag">${q.id} · ${q.topic}</span>
        ${prioridadLabel}
        ${counterBadge}
      </div>
      ${q.contexto ? `<div class="contexto">${q.contexto}</div>` : ""}
      <h3>${q.enunciado}</h3>
      <div id="phase-content"></div>
    </div>
  `;
  if (state.phase === "recall") drawRecallPhase(q);
  else if (state.phase === "feedback") drawFeedbackPhase(q);
  else if (state.phase === "mc") drawMCPhase(q);
}

function drawRecallPhase(q) {
  const pc = $("#phase-content");
  pc.innerHTML = `
    <span class="phase-label">Fase 1 · Recall libre</span>
    <div class="recall-area">
      <textarea id="recall-input" placeholder="Escribí lo que recordás de la respuesta. No importa la extensión: el esfuerzo de recordar es lo que fija el contenido."></textarea>
      <div class="recall-hint"><b>Pista:</b> ${q.pista}</div>
    </div>
    <div class="btn-row">
      <button class="btn" id="btn-show-answer">Ver respuesta modelo</button>
      <button class="btn secondary" id="btn-skip">Saltar pregunta</button>
    </div>
  `;
  $("#btn-show-answer").addEventListener("click", () => { state.phase = "feedback"; drawQuestion(); });
  $("#btn-skip").addEventListener("click", () => { reinsertLater(q); renderQuestion(); });
}

function drawFeedbackPhase(q) {
  const pc = $("#phase-content");
  pc.innerHTML = `
    <span class="phase-label">Fase 2 · Respuesta modelo</span>
    <div class="feedback">
      <h4>Respuesta correcta</h4>
      <div class="bloque">${q.respuestaLibre.replace(/\n/g, "<br>")}</div>
      <h4>Explicación</h4>
      <p>${q.explicacion}</p>
      <h4>Error típico — marcá bien este límite</h4>
      <div class="error-tipico"><b>⚠</b> ${q.errorTipico}</div>
    </div>
    <div class="btn-row">
      <button class="btn" id="btn-to-mc">Continuar → Refuerzo con opciones</button>
    </div>
  `;
  $("#btn-to-mc").addEventListener("click", () => { state.phase = "mc"; drawQuestion(); });
}

function drawMCPhase(q) {
  const pc = $("#phase-content");
  const opcionesIdx = q.opciones.map((_, i) => i);
  shuffle(opcionesIdx);
  let optsHtml = opcionesIdx.map((realIdx, displayIdx) => {
    const letter = String.fromCharCode(65 + displayIdx);
    return `<li data-real="${realIdx}"><span class="letter">${letter}</span>${q.opciones[realIdx]}</li>`;
  }).join("");
  pc.innerHTML = `
    <span class="phase-label">Fase 3 · Refuerzo con opciones</span>
    <ul class="options" id="options-list">${optsHtml}</ul>
    <div id="mc-feedback"></div>
  `;
  pc.querySelectorAll("#options-list li").forEach(li => {
    li.addEventListener("click", () => handleMCAnswer(q, li));
  });
}

function handleMCAnswer(q, liClicked) {
  const realIdx = parseInt(liClicked.getAttribute("data-real"));
  const isCorrect = realIdx === q.correcta;
  const p = getProgress(q.id);
  p.attempts++;
  document.querySelectorAll("#options-list li").forEach(li => {
    li.classList.add("disabled");
    const r = parseInt(li.getAttribute("data-real"));
    if (r === q.correcta) li.classList.add("correct");
    else if (li === liClicked) li.classList.add("wrong");
  });
  if (isCorrect) {
    p.okCount++;
    state.sessionStats.ok++;
    if (p.okCount >= 2) p.mastered = true;
  } else {
    p.errCount++;
    state.sessionStats.err++;
    p.okCount = 0;
  }
  saveProgress();
  updateProgressBar();
  const fb = $("#mc-feedback");
  const verdict = isCorrect
    ? (p.mastered ? "✓ DOMINADA — dos aciertos consecutivos" : "✓ Correcto — necesitás un acierto más para dominarla")
    : "✗ Incorrecto — la pregunta volverá a aparecer más adelante";
  fb.innerHTML = `
    <div class="feedback ${isCorrect ? 'ok' : 'err'}">
      <div class="veredicto">${verdict}</div>
      ${!isCorrect ? `
        <h4>Respuesta correcta</h4>
        <p>${q.respuestaLibre.replace(/\n/g, "<br>")}</p>
        <h4>Error típico</h4>
        <div class="error-tipico"><b>⚠</b> ${q.errorTipico}</div>
      ` : ""}
    </div>
    <div class="btn-row">
      <button class="btn" id="btn-next">Continuar →</button>
    </div>
  `;
  if (!isCorrect && !p.mastered) reinsertLater(q);
  $("#btn-next").addEventListener("click", () => {
    if (state.queue.length === 0) renderSummary();
    else renderQuestion();
  });
}

function renderSummary() {
  const mastered = QUESTIONS.filter(q => isMastered(q.id));
  const weak = QUESTIONS.filter(q => !isMastered(q.id) && getProgress(q.id).attempts > 0);
  const untouched = QUESTIONS.filter(q => getProgress(q.id).attempts === 0);
  $("#sum-mastered").textContent = mastered.length;
  $("#sum-weak").textContent = weak.length + untouched.length;
  $("#sum-ok").textContent = state.sessionStats.ok;
  $("#sum-err").textContent = state.sessionStats.err;
  const listWeak = $("#list-weak");
  const allWeak = [...weak, ...untouched];
  if (allWeak.length === 0) {
    listWeak.innerHTML = '<li style="border-left-color:var(--ok); background:var(--ok-bg); color:var(--ok);">No hay temas débiles. ¡Sesión perfecta!</li>';
  } else {
    listWeak.innerHTML = allWeak.map(q => {
      const p = getProgress(q.id);
      const estado = p.attempts === 0 ? "no intentada" : `${p.errCount} error(es)`;
      return `<li><span class="q-id">${q.id}</span><b>${q.topic}</b> <span style="color:var(--text-dim); font-size:12px; margin-left:6px;">(${estado})</span></li>`;
    }).join("");
  }
  const listMastered = $("#list-mastered");
  if (mastered.length === 0) {
    listMastered.innerHTML = '<li style="color:var(--text-dim); background:var(--bg-3); border-left-color:var(--border);">Todavía no dominaste ninguna pregunta.</li>';
  } else {
    listMastered.innerHTML = mastered.map(q => `<li><span class="q-id">${q.id}</span>${q.topic}</li>`).join("");
  }
  showScreen("screen-summary");
}

function initFlashcards() {
  const order = { critico: 0, alto: 1, medio: 2 };
  const sorted = [...QUESTIONS].sort((a,b) => order[a.priority] - order[b.priority]);
  const groups = { critico: [], alto: [], medio: [] };
  sorted.forEach(q => groups[q.priority].push(q));
  Object.values(groups).forEach(g => shuffle(g));
  state.flashcards.order = [...groups.critico, ...groups.alto, ...groups.medio];
  state.flashcards.index = 0;
  state.flashcards.revealed = false;
}

function renderFlashcard() {
  const fc = state.flashcards;
  const q = fc.order[fc.index];
  const p = getProgress(q.id);
  const body = $("#flashcard-body");

  $("#fc-current").textContent = fc.index + 1;
  $("#fc-total").textContent = fc.order.length;

  renderFlashcardDots();

  let statusHtml = "";
  if (p.mastered) statusHtml = '<span class="fc-status mastered">✓ Dominada</span>';
  else if (p.errCount > 0) statusHtml = '<span class="fc-status weak">⚠ Tema débil</span>';

  let html = `
    <div class="fc-tag">${q.id} · ${q.topic}</div>
    ${statusHtml}
    ${q.contexto ? `<div class="fc-context">${q.contexto}</div>` : ""}
    <div class="fc-question">${q.enunciado}</div>
  `;

  if (fc.revealed) {
    html += `
      <div class="fc-answer">
        <div class="feedback">
          <h4>Respuesta</h4>
          <div class="bloque">${q.respuestaLibre.replace(/\n/g, "<br>")}</div>
          <h4>Explicación</h4>
          <p>${q.explicacion}</p>
          <h4>Error típico</h4>
          <div class="error-tipico"><b>⚠</b> ${q.errorTipico}</div>
        </div>
        <div class="fc-self-eval">
          <button class="btn err" id="fc-costo">😕 Me costó</button>
          <button class="btn ok" id="fc-sabia">😊 La sabía</button>
        </div>
      </div>
    `;
  } else {
    html += `
      <div style="margin-top:auto;">
        <button class="btn" id="fc-reveal" style="width:100%; justify-content:center;">Mostrar respuesta</button>
      </div>
    `;
  }

  body.innerHTML = html;

  if (fc.revealed) {
    $("#fc-costo").addEventListener("click", () => handleFlashcardEval(q, false));
    $("#fc-sabia").addEventListener("click", () => handleFlashcardEval(q, true));
  } else {
    $("#fc-reveal").addEventListener("click", () => {
      state.flashcards.revealed = true;
      renderFlashcard();
    });
  }

  $("#fc-prev").disabled = fc.index === 0;
  $("#fc-next").disabled = fc.index === fc.order.length - 1;
}

function renderFlashcardDots() {
  const fc = state.flashcards;
  const dots = fc.order.map((q, i) => {
    const p = getProgress(q.id);
    let cls = "dot";
    if (i === fc.index) cls += " current";
    else if (p.mastered) cls += " mastered";
    else if (p.errCount > 0) cls += " weak";
    return `<div class="${cls}" title="${q.id}: ${q.topic}"></div>`;
  }).join("");
  $("#fc-dots").innerHTML = dots;
}

function handleFlashcardEval(q, knewIt) {
  const p = getProgress(q.id);
  p.attempts++;
  if (knewIt) {
    p.okCount++;
    state.sessionStats.ok++;
    if (p.okCount >= 2) p.mastered = true;
  } else {
    p.errCount++;
    state.sessionStats.err++;
    p.okCount = 0;
  }
  saveProgress();
  updateReviewOnlyButtonVisibility();

  const fc = state.flashcards;
  if (fc.index < fc.order.length - 1) {
    fc.index++;
    fc.revealed = false;
  } else {
    fc.revealed = false;
  }
  renderFlashcard();
}

      if (target) target.scrollIntoView({ behavior: "smooth", block: "start" });
      if (window.innerWidth <= 900) {
        $("#material-toc").classList.remove("open");
        $("#toc-toggle").classList.remove("open");

    });

    const toc = $("#material-toc");
    const toggle = $("#toc-toggle");
    const isOpen = toc.classList.toggle("open");
    toggle.classList.toggle("open", isOpen);
    toggle.querySelector("span:first-child").textContent = isOpen ? "📑 Ocultar índice" : "📑 Ver índice";
  });
